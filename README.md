# Сектор 5×5

Браузерный тактический шутер (three.js): закладка бомбы, командный бой, боты, кейсы, рынок, кланы.

- `index.html` — вся игра одним файлом.
- `download.html` — страница скачивания (APK + игра в браузере).
- `.github/workflows/pages.yml` — публикует сайт на GitHub Pages.
- `.github/workflows/android.yml` — собирает APK и кладёт его в Releases → `latest`.

Онлайн-функции (рынок между игроками, кланы, сообщения, комнаты, админка) работают в версии на claude.ai. Для приложения нужен свой сервер — см. `server/`.
